## About the project

CarePath SL is a **proposed** community healthcare access and referral support system for Sierra Leone. It helps people find health facilities that offer the service they need, shows how recent the facility information is, gives urgent-assessment guidance when emergency warning signs are reported, and works with saved records when there is no internet. It supports English and Krio.

This repository contains the **logical design only** (no source code), as required by the assignment: it is a proposed design, not a deployed or clinically validated service.

## Problem

People may travel to a health facility that does not offer the service they need, then lose time and money travelling again. Emergency help must never depend on payment.
