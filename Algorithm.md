# CarePath SL – Algorithm

1. Start CarePath SL.
2. Ask the user to choose English or Krio.
3. Check whether an internet connection is available.
4. If online, retrieve the latest facility records from the authorised data source. If offline, load saved records and mark them as potentially outdated.
5. Ask for the user's location or preferred area and the service they are looking for.
6. Check that the required search information has been provided. If information is missing, explain what is needed and ask again or allow the user to exit.
7. Ask a short, carefully reviewed safety question about possible emergency warning signs. Do not attempt to diagnose the user.
8. If the user indicates possible emergency warning signs, immediately display advice to seek urgent clinical assessment and show verified emergency contacts if available. Do not make this guidance conditional on payment or account registration.
9. Otherwise, find facilities recorded as offering the requested service and serving the selected area.
10. Check the reported availability and the last verification time for each matching facility.
11. Rank suitable options in this order: service suitability, verified and recent availability, then distance or travel-area estimate.
12. Display the options, their recorded services, availability status, last verification time and any uncertainty. If no suitable match is recorded, explain this and provide a safe next step.
13. Ask whether the user wants another search. If yes, repeat from the location/service step. If no, end the session.
